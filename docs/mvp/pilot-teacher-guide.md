# Pilot — Teacher guide (one pager)

**Support during pilot week:** reply in the pilot WhatsApp/Telegram group, or email `support@kasina.et` (update if you use a different inbox).

Kasina needs a network connection. Airplane mode will not work — students will see a clear offline message.

---

## 1. Login

1. Open **https://kasina.et** (or `https://www.kasina.et`).
2. Tap **Teacher login** (or go to `/teacher/login`).
3. Sign in with the email/password you were given.

First time only: use **Create account** (`/teacher/signup`), then ask the ops lead to run seed if you need the demo class.

---

## 2. Create / share invite

1. Open **Dashboard** (`/teacher`).
2. Under **Create class**, enter a name (e.g. `Section 12A`) → **Create class**.
3. Open the class card → copy the **invite code** (8 characters).
4. Share that code with students (board, SMS, or chat).

Demo seed class invite (if seeded): **DEMO2026**.

---

## 3. Create an assignment

1. Open the class → **Create assignment** (or the green **+ Assign Practice** button).
2. Title example: `Power Rule · 10 questions`.
3. Mode: **Topic practice** → Unit `Calculus` → Topic `Power Rule`.
4. Count `10` → **Create assignment**.

Tip: on **Class results**, tap a weak topic **Assign →** to prefill this form.

---

## 4. Where to see results

| View | Path |
|------|------|
| Class roster + assignments | `/teacher/classes/[id]` |
| Who finished an assignment | `/teacher/assignments/[id]` |
| Class scores + weak topics | `/teacher/classes/[id]/results` |
| Overview heatmap | `/teacher` (primary class) |

**Done** = student completed at least one session for that assignment (latest score counts).

---

## Student instructions (hand this out)

Print or share [pilot-student-handout.md](./pilot-student-handout.md). Summary:

1. Open the pilot URL → **Get Started** (or **Join class**).  
2. Enter the **invite code**, your name, email, and password → join.  
3. On home, tap **Start** on the assignment → answer questions → finish.

Returning students: **Student login** on the landing page.
